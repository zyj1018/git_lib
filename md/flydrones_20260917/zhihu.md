# FlyDrones：把一只果蝇的大脑装进无人机，浏览器里就能看它自己飞

用 MaleCNS v1.0 果蝇连接组（官方论文口径 166,691 个神经元）当飞手——代码 MIT；已有电脑时在线试玩不增加硬件购置费，真机预算见估算说明

![FlyDrones 官方演示：被果蝇大脑驾驶的四轴无人机](https://cdn.jsdelivr.net/gh/zyj1018/git_lib@master/diy-lab/img/flydrones_20260917/hero_f3.jpg)

> 官方演示动画截图（仓库 assets/hero.gif 帧）：3D 卧室里这架四轴不是被遥控器操纵的，屏幕右下角实时滚动的是 MiniFly 简化电路的模拟放电——按 S 键还能甩拍子打它，看巨纤维神经来不来得及触发逃逸。

你把手掌摊开在摄像头前，它往上爬；握拳，它悬停；手掌猛地冲向镜头，它像真果蝇一样“闪”一下躲开。

真正参与高层方向决策的是一张生物接线图，但 FlyDrones 仍包含视觉处理、指令解码、安全限制和硬件适配，低层姿态稳定则由无人机自带飞控完成。2026 年 9 月 3 日，HHMI Janelia、剑桥大学、MRC LMB 与 Google Research 团队在《Cell》正式发表雄性果蝇完整中枢神经系统连接组 MaleCNS v1.0。论文给出的口径是 166,691 个神经元、46 million 个突触前位点连接到 312 million 个突触后致密区，人工校对工作量估计为 44 人年；数据按 CC-BY 4.0 授权。FlyDrones 的做法，是把这套连接组模型接到无人机的高层摇杆指令上。

## 先看它会什么

**【官方已实现】** **浏览器仿真已经跑通，真机适配代码也已提供：连接组模型只管高层方向，姿态交给无人机自己的飞控；但作者尚未完成真机实飞验证。**

**01**　浏览器里 10 秒开飞：不用装 Python、不用买无人机、不用显卡，打开网页就能看它飞、看神经元一颗颗放电。

**02**　一个大脑，三个飞手：官方命令 **flydrones swarm** 把同一张接线图复制成三份互不干扰的活动，各自飞一台无人机。

**03**　真连接组随时可换：先下载约 1.2 GB 的 MaleCNS 官方数据，再构建按条件筛选的连接图；官方数据含 166,691 个神经元，实际构建保留的神经元与连接数取决于过滤条件。

![FlyDrones 在线演示界面 HUD](https://cdn.jsdelivr.net/gh/zyj1018/git_lib@master/diy-lab/img/flydrones_20260917/social.png)

> 官方社交预览图（仓库 assets/social.png）：在线演示的实时状态栏写着 850 NEURONS / 4,928 CONNECTIONS，画面正在跑“拍苍蝇”小游戏——拍子扫过来时触发的是真实果蝇的巨纤维逃逸通路。注意这 850 个神经元是演示用的简化电路，不是 16.67 万的真连接组。

## 它为什么值得玩

过去半年我们发过的开源机器人大多是“工程派”：更便宜的结构件、更稳的控制环、更快的固件。FlyDrones 是“生物派”——连接组模型不直接计算电机转速或姿态 PID；项目把电镜重建的接线图跑成脉冲网络，让神经活动参与决定高层摇杆方向。最有意思的是它的克制：神经环路只输出高层摇杆指令，姿态稳定仍然是无人机自己飞控的活；两者之间还插了一个大脑之外的“安全官”，随时有权否决。深挖一层你还会发现它的诚实——作者专门写了一页文档，把哪部分是生物学、哪部分是他们自己拍脑袋补的工程桥，一条条列清楚。

**【本文核对】** 仓库创建于 2026-09-15；CHANGELOG 记录到 0.1.2（2026-09-16），但 pyproject.toml 的包版本仍是 0.1.0。项目采用 MIT 协议，含仿真器、MaleCNS 加载器、安全模块、四种真机后端和测试。但作者在硬件文档里写得很明白：Tello、Crazyflie、MAVLink、ESP32 四个适配器是照着官方 SDK 写的，**作者自己还没有实飞验证过**。所以正确的打开方式是：先在电脑上玩通，真机只是最后一公里的冒险。

## 它是怎么工作的

整条链路可以按“感知—决策—执行”来读。感知：摄像头画面被切成复眼网格，算逐格光流和逼近量；决策：这些信号驱动连接组里的运动神经元，脉冲沿着按突触计数接出来的线传播，最后落到几组“下降神经元”上；执行：下降神经元的放电率被线性换算成油门、偏航、前进三条摇杆量，过一遍安全官，再交给无人机自己的飞控。连接组模型内部没有姿态 PID；神经元放电会先经过项目的线性读出、指令限幅与安全官，再交给无人机飞控。

![FlyDrones 感知-决策-执行系统结构图](https://cdn.jsdelivr.net/gh/zyj1018/git_lib@master/diy-lab/img/flydrones_20260917/system_diagram.png)

> 本文自绘，依据官方 README 与 docs/SCIENCE.md 的信道映射整理：谁负责感知（复眼与光流）、谁负责计算（连接组脉冲网络）、谁负责动作（下降神经元到摇杆，再经安全官）。

**输入：**无人机摄像头或电脑摄像头画面，加上无人机陀螺仪的偏航角速度（在果蝇身上这个角色由平衡棒承担）。

**处理：**普通笔记本可实时跑 MiniFly 和传感—运动子图；完整 MaleCNS 需要约 8 GB 内存，速度取决于 CPU，不能一概保证实时。神经元采用泄漏积分点火模型（参数取自 Shiu 等人 2024 年《Nature》的果蝇脑模型）；浏览器版是 JavaScript 实现，仓库测试用于检查它与 Python 版的一致性。

**输出：**三条 −1 到 1 的摇杆指令（升降速度、偏航角速度、前进速度）。真机上，Tello 用官方 RC 接口，Crazyflie 用悬停设定点，ArduPilot/PX4 走 GUIDED / OFFBOARD 速度设定点，Betaflight 机型则靠一块 ESP32 通过 MSP 协议桥接。

## 动手清单：先把成本说清楚

![FlyDrones 成本口径表](https://cdn.jsdelivr.net/gh/zyj1018/git_lib@master/diy-lab/img/flydrones_20260917/bom_card.png)

> 本文自绘，依据官方 README / docs/HARDWARE.md 的平台清单整理；价格为 2026-09 国内电商粗略估算。已有电脑时软件路径可不新增硬件购置，和约 500 元起的真机路径是两件事。

• 主控与计算：你自己的笔记本（4 核 CPU 即可跑演示版；完整连接组建议 8 GB 内存）。

• 感知与交互：摄像头（手势输入用 MediaPipe，没装则回退到 OpenCV 肤色检测）；真机模式下用无人机自带的视频流。

• 执行与结构：可选真机 DJI/Ryze Tello，或 27 克的 Crazyflie 2.1 加 Flow deck，或给 Betaflight/INAV 机加一块 ESP32 桥板。

• 软件与服务：Python 3.10 以上；首次安装、MediaPipe 手部模型和 MaleCNS 数据下载需要联网，下载完成后的本机模拟不依赖云端推理或大模型 API；连接组数据来自 Janelia 公共存储桶，按 CC-BY 4.0 授权。

• 成本结论：已有电脑时，浏览器与本机模拟路径的新增硬件购置费可为 0 元；这不等于真机全流程 0 元，也未计网络、电力和既有电脑成本。真机“500 元起”是 2026-09 国内电商粗略估算，并非官方 BOM 或售价，请以实际下单价为准。

## 一分钟判断值不值得动手

**复现难度：**模拟器路径 ★★☆☆☆（会装 Python 就行）；真机路径 ★★★★☆（要会看无人机的失控保护设置）。**首次跑通：**网页版约 1 分钟；本机模拟器约 15 分钟（本文经验性估计，受网络和电脑性能影响）。**完整装配：**真连接组从下载到跑通约 30—60 分钟、真机调试另需半天（本文估计，并非官方承诺）。**预算：**已有电脑时软件路径新增购置费可为 0 元；可选真机约 500 元起（2026-09 国内电商粗略估算）。**必需条件：**一台普通电脑；想玩手势再加一个摄像头；想真飞需要空旷室内场地与桨叶保护。**适合人群：**想给孩子讲“感知—决策—执行”的家长与老师、做具身智能入门的同学、对神经科学好奇的工程师。

## 最短复现路线

**第1步　先玩网页版**打开 spikecalls.github.io/FlyDrones，按 S 甩拍子，点右侧 Brain 面板刺激任意神经元组，按 1—6 试手势键。成功标志：点 LPLC2 时画面里的无人机出现逃逸动作，脉冲面板同步爆出一串放电。卡住先查：页面没加载先换浏览器或关掉拦截脚本的插件，这个演示是纯前端 three.js，不需要后端。

**第2步　本机跑仿真**克隆仓库，建虚拟环境，**pip install -e ".[vision]"**，然后 **flydrones demo --live**。成功标志：弹出四个面板——无人机相机与复眼网格、实时脉冲光栅、俯视的房间、过完安全官之后的指令；脚本手做“张开—握拳—右移—逼近—撤下”，无人机跟着升降与转向。卡住先查：先跑 flydrones --version 和 pytest -q，确认装的是完整包而不是只装了核心。

**第3步　打开大脑看看**运行 **flydrones inspect**，它会打印每个输入输出组匹配到多少神经元，然后逐个刺激。成功标志：刺激 T4c_L（左眼向上运动）时 DNg02 升力神经元放电上升；刺激 LPLC2_L 时 DNp01（巨纤维）和 DNp03 同时响应。卡住先查：某组匹配到 0 个神经元，通常是细胞类型名或左右侧写错了，对照 configs 里的默认分组重来。

**第4步　换成真连接组****flydrones download malecns**（约 1.2 GB）→ **flydrones build-brain** → **flydrones calibrate** → 用 malecns 配置再跑一次 demo。成功标志：命令打印出你筛选条件下保留了多少神经元和连接，标定会给出升力与偏航两组读出权重的拟合优度。卡住先查：构建阶段内存吃紧就加 --core-hops 3，只保留眼睛与下降神经元之间几跳以内的神经元。

**第5步　最后才是真机**先 **--drone sim** 跑同一份配置，再对真机做一次干跑（不加 --send，只打印指令），确认每个手势对应的指令方向都合理，才加 --send。成功标志：干跑时张开手掌打印出的升降指令为正、握拳回到 0、手掌逼近时出现一次短促的逃逸爬升。卡住先查：方向反了就改配置里的读出增益或偏航饱和值，不要靠改连接组来凑。

![FlyDrones Python 仪表盘运行截图](https://cdn.jsdelivr.net/gh/zyj1018/git_lib@master/diy-lab/img/flydrones_20260917/demo_f12.jpg)

> 官方演示动画帧（仓库 assets/demo.gif）：本机仪表盘用脚本化的手势跑完整套动作，标题栏会老实打印神经元数量、连接数量和大脑相对实时的运行倍率。做到这一步，就算首次跑通了。

## 新手最容易卡在哪里

**现象：**在本机 demo 里手怎么挥，无人机都不动。**先判断：**先分清是“手势没进来”还是“大脑没响应”——用键盘手势键 1—6 试一遍就能区分开。**正确做法：**键盘有效说明是摄像头链路问题：补装 gestures 依赖，确认输入参数选了 gesture 或 both，再看光照是否足够。

**现象：**跑真连接组时机器卡死或构建中断。**先判断：**构建期需要读 1.1 GB 的突触权重表、峰值占用约 6 GB 空闲内存，磁盘和内存任一不够都会失败。**正确做法：**先用 --core-hops 3 做传感器运动核，再考虑整脑；下载支持断点续传，重跑不会从头开始。

**现象：**真机起飞后自己往上飘，或者动不动就触发逃逸。**先判断：**先看是“静止时的基线漂了”还是“读出增益过大”——干跑日志里静止段的指令是否接近 0。**正确做法：**静止漂移就延长标定时间或调 DNg02 的基调驱动偏置；逃逸太频繁就抬高逃逸阈值与逼近量下限，同时先把最大油门压到三成。

## 还能怎么魔改

**【魔改设想】** **入门：**改配置不改代码。把巡航前进速度调大一点，让它从“原地悬停”变成“贴着房间边缘巡一圈”；或者关掉脚本手，用手势键当遥控器，给家里人表演一次“用手喂果蝇开飞机”。

**【魔改设想】** **进阶：**把“果蝇”换成别的脑子。仓库的 Drone 接口只有起飞、发指令、读遥测、取帧、降落五个方法，照着写一个自己的子类，就能把同一套神经环路接到小车、船模甚至机械臂上——社区里已经有人把它接到游戏和仿真身体上。

**【魔改设想】** **高阶：**给连接组加上可塑性。官方明确说现在不会学习、权重是固定的，多巴胺类可塑性在路线图上——这正是做课程设计或科研小课题的口子：让果蝇学会绕开一个固定障碍，看权重怎么变。

## 冷静提醒：边界与安全

**安全提醒：**这不是玩具。桨叶高速旋转会割伤人和宠物，锂电池怕碰撞与过充；室内试飞必须装桨叶保护、清出 3 米乘 3 米区域、机身前方不要站人，并且手边要留着厂商 App 或遥控器随时接管。户外飞行要先查当地实名登记与禁飞区规定，不要在人群、道路、动物上方飞。仓库默认是“干跑”模式，只有加 --send 才会真的发指令——请一直保持这个习惯，直到你完全确信指令是对的。

还要分清三件事。第一，这是计算模型，不是复活了的果蝇：接线来自电镜数据，动力学用的是标准脉冲神经元模型，模型里没有树突、没有神经调质、没有可塑性，不可能“有意识”。第二，工程边界很实在：运动视觉是作者用软件算的光流、绕过了真实果蝇的早期视觉层；循环跑 20—50 赫兹，而真果蝇扇翅每秒约 200 次；作者自己的硬件适配器也还没实飞验证。第三，网页演示跑的是 850 个神经元的简化电路，不是 16.67 万的真连接组——想看真的，就在本机跑 build-brain。
